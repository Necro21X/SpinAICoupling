# Project Planning Boilerplate

This folder contains starter templates for planning work in this repository.

## Templates
- [`PROJECT_PLAN.md`](./PROJECT_PLAN.md): high-level scope, goals, and delivery plan
- [`MILESTONES.md`](./MILESTONES.md): milestone breakdown and tracking
- [`TASK_BACKLOG.md`](./TASK_BACKLOG.md): actionable task list and ownership

## How to use
1. Copy each template section and fill in project-specific details.
2. Keep status fields up to date as work evolves.
3. Review weekly and adjust priorities.
